Como Jogar

No ano de 2150, a Inteligência Artificial ERIS apagou todos os registros das descobertas feitas por mulheres cientistas.

Você faz parte do Projeto Athena. Sua missão é explorar cada laboratório, investigar objetos, encontrar pistas escondidas e resolver os enigmas para recuperar os arquivos históricos.

  • Clique nos objetos do cenário para investigá-los.
  • Itens encontrados vão para o inventário lateral.
  • Use o computador e o terminal para descobrir códigos.
  • Insira o código correto no teclado da porta para avançar.

Dica: nada é decorativo por acaso. Datas, nomes e números escondem respostas.
